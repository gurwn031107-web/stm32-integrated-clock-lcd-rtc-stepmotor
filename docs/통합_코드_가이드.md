# 통합 시계 코드 가이드

## 1. 완성한 동작
- TimeClock 모드: 모터 3개가 RTC의 시·분·초를 표시. FND는 분·초, LCD 첫 줄은 시각, 둘째 줄은 날짜·요일.
- Stopwatch 모드: 모터 3개가 스톱워치의 시·분·초를 표시. FND는 분의 일 자리·초·0.1초, LCD 첫 줄은 실제 시각, 둘째 줄은 스톱워치 시·분·초·0.01초.
- 시침은 12시간 한 바퀴. 13시는 1시 위치. 분침은 초까지, 시침은 분·초까지 반영하여 중간 위치를 가리킴.
- 모드가 바뀌면 현재 위치에서 새 목표까지 짧은 방향으로 이동. 모터 3개는 같은 타이머 틱에서 각각 한 스텝씩 진행.
- 스톱워치는 RUN이면 시계 모드에서도 계속 증가. 모드 전환은 표시할 시간의 선택이며 시간 자체의 정지가 아님.
- STOP은 카운터를 정지. 바늘이 아직 목표에 도착하지 않았다면 정지한 최종 값까지 이동한 뒤 코일을 유지.
- CLEAR는 STOP에서 수행. 숫자는 즉시 0, 바늘은 물리적인 이동 시간이 걸려 12시로 복귀.

## 2. 배선과 조작
각 행은 반드시 ULN2003 IN1 → IN2 → IN3 → IN4 순서.

| 바늘 | IN1 | IN2 | IN3 | IN4 |
|---|---|---|---|---|
| 시 | PC10 | PC11 | PC12 | PD2 |
| 분 | PC9 | PC8 | PC6 | PC5 |
| 초 | PA0 | PA1 | PA4 | PB0 |

- PC0: 떼었을 때 모드 전환.
- PC1: Stopwatch 모드에서 눌렀을 때 실행/정지.
- PC3: Stopwatch가 정지 상태일 때 눌렀다 떼면 초기화.
- PB15: 시계 모드 LED / PB14: Stopwatch 모드 LED.
- PB13: Stopwatch 정지 LED / PC4: Stopwatch 실행 LED. 현재 모드와 별개로 실제 RUN/STOP 상태 표시.
- PB8=SCL, PB9=SDA. LCD 0x27, DS3231 0x68 (7비트 주소).
- 기존 FND와 버튼 배선 유지. 버튼은 기존 active-low 외부 풀업 회로 기준.
- 모터 전원은 5V 정격 모터 기준 외부 5V 전원에 연결하고, ULN2003 3개와 STM32의 GND를 공통 연결. GPIO는 ULN2003 입력에 연결하며 모터 코일을 직접 구동하지 않음.

## 3. 전원 투입과 원점
이 회로에는 원점 센서/엔코더가 없다. 프로그램의 position=0은 실제 바늘이 12시라는 가정이다.
전원을 넣거나 MCU를 리셋하기 전에 세 바늘을 12시 방향으로 맞춰야 한다.
리셋만 해도 소프트웨어 위치는 0으로 초기화되므로, 이전에 움직인 바늘을 그대로 두고 리셋하면 표시가 어긋난다.
최초 여자 시 회전자가 코일 위상에 정렬되며 작은 오차가 생길 수 있어 실제 바늘 장착 위치 보정이 필요하다.
자동 원점 복귀가 필요하면 모터별 센서를 추가해야 한다. CLEAR는 저장한 위치에서 0으로 돌아가는 동작이며 센서로 원점을 찾는 동작은 아니다.

ClockNeedle.h:
- NEEDLE_STEPS_PER_REV = 4096: 수업의 28BYJ-48 하프스텝 명목값. 실제 감속비/모터에 맞춰 한 바퀴를 실측하여 보정.
- NEEDLE_STEP_INTERVAL_MS = 2: 한 스텝 간격 2ms. 부하 때문에 탈조하면 3~5ms 등으로 늘려 시험.
ClockNeedle.c:
- pins[3]: 시/분/초 핀 배열.
- forward[3]: 실제 시계방향에 대응하는 드라이버 방향. 한 모터만 반대로 돌면 그 항목만 CW ↔ CCW 변경.
4096스텝, 2ms 기준 반 바퀴 최대 이동 시간은 약 4.1초. 3개는 순차 완주가 아니라 함께 이동한다.
이 코드는 개방루프이므로 탈조/손으로 바늘 이동/전원 차단을 스스로 검출하지 못한다.

## 4. 먼저 읽을 흐름
main.c → ap_main.c → TimeClock/StopWatch → ClockNeedle.c → StepMotor.c → Display.c 순으로 읽기.

main()
  → HAL, GPIO, TIM3, TIM4, I2C1 초기화
  → ap_main()
      → ap_init()
          → StopWatch_init(): 0, STOP, 버튼 연결
          → TimeClock_init(): I2C 핸들 연결, RTC 시간 읽기
          → Disp_init(): LED 연결, LCD 초기화
          → ClockNeedle_init(): 모터 핀 연결, 현재 위치 0, 초기 코일 위상 유지
          → TIM3/TIM4 인터럽트 시작
      → 무한 반복
          → 모드 버튼 확인
          → RTC 100ms 주기 갱신
          → 스톱워치 버튼 처리
          → 시계/스톱워치 스냅샷 읽기
          → 모드에 맞는 시간을 ClockNeedle_setTime()에 전달
          → 50ms마다 LED/FND/LCD 표시 요청

무한 반복과 별개로:
TIM3 1ms → HAL_TIM_PeriodElapsedCallback()
  → Disp_ISR() → FND 스캔
  → ClockNeedle_ISR() → 2ms마다 모터별 최대 한 스텝
TIM4 10ms → HAL_TIM_PeriodElapsedCallback()
  → TimeClock_ISR(): DP 점멸용 카운터
  → StopWatch_ISR(): RUN일 때만 0.01초 증가

오늘 실습의 TIM9를 그대로 더하지 않고, 기존 TIM3의 1ms 틱을 공유했다.
LCD I2C 전송과 버튼 디바운스는 main 쪽에서 실행되므로 모터 펄스가 main의 작업 시간에 묶이지 않는다.
인터럽트에서는 I2C, HAL_Delay, 문자열 포맷을 실행하지 않는다. 한 번에 모터당 한 스텝만 출력한다.
수업의 boolean flag를 main에서 처리하면 LCD 작업 중 여러 틱이 하나로 합쳐질 수 있어, 이 통합본은 짧은 GPIO 출력을 ISR에서 직접 처리한다.

## 5. Core, 서비스, 드라이버 역할
| 파일/함수 | 맡은 일 |
|---|---|
| ap_main.c | 모드 선택, 초기화 순서, 데이터 전달, 타이머 콜백 연결 |
| TimeClock_task | DS3231의 7개 시간·날짜 레지스터를 100ms마다 읽어 저장 |
| StopWatch_ISR | 10ms마다 스톱워치 카운터 증가 및 자리올림 |
| StopWatch_taskEnabled | 양 모드에서 버튼 상태 추적, SW 모드에서만 실행/정지/초기화 반영 |
| StopWatch_getTimeData | 잠깐 인터럽트를 막고 한 시점의 시간 복사. 자리올림 도중 섞인 값 방지 |
| ClockNeedle_setTime | 시·분·초를 바늘의 목표 스텝으로 변환하고 3개를 함께 게시 |
| ClockNeedle_ISR | 실제로 출력한 스텝 위치와 목표 비교, 이동 방향 결정 |
| StepMotor_stepPhase | 8개 여자 패턴에서 다음/이전 패턴 선택 후 GPIO 출력 |
| StepMotor_hold | 현재 여자 패턴 유지 |
| StepMotor_release | 전체 코일 OFF. 정상 바늘 대기 중에는 호출하지 않음 |
| Display.c | FND 숫자/DP, LCD 문자열, LED 표시 |
| ds3231.c / lcd.c | I2C 장치 프로토콜 처리 |

Core의 구조체와 Display 구조체를 typedef로 공유하여 서로 다른 구조체 포인터로 강제 형변환하지 않는다.
Display는 전달받은 스냅샷을 호출 중에만 읽고 포인터를 장기 저장하지 않는다.

## 6. 목표 위치 계산
N = NEEDLE_STEPS_PER_REV

초침 = 초 × N / 60
분침 = (분 × 60 + 초) × N / 3600
시침 = ((시 % 12) × 3600 + 분 × 60 + 초) × N / 43200

예: 03:00:00 → 시침 N/4, 분침 0, 초침 0.
예: 06:30:30 → 시침은 6과 7 사이, 분침은 30분을 조금 지난 위치, 초침은 반 바퀴.
정수 나눗셈의 소수 부분은 버려지므로 각도는 한 스텝 단위로 양자화된다.

target: 가야 할 위치. main에서 갱신.
position: 실제 출력한 스텝을 세어 추정한 위치. ISR에서만 변경.
stepCounter: 모터의 8가지 전기적 여자 패턴 인덱스. 바늘의 4096단계 위치와 다르다.

distance = (target + N - position) % N
- 0: 도착. 패턴 유지.
- N/2 이하: 정방향 1스텝.
- N/2 초과: 역방향 1스텝.

59초 → 0초에서 초침은 뒤로 거의 한 바퀴 돌지 않고, 앞쪽으로 남은 약 1초 구간만 이동한다.
모드 변경이나 CLEAR에서도 현재 position은 지우지 않고 목표만 바꿔야 실제 바늘과 소프트웨어 위치가 이어진다.

## 7. 유지·수정한 기존 기능
- TIM3 FND 스캔 / TIM4 Stopwatch 카운트 분리 유지.
- RTC와 스톱워치는 모드에 관계없이 갱신, 출력만 모드에 따라 선택.
- RTC getDateTime의 누락된 I2C 읽기 복원. 실패한 읽기는 이전 정상 값을 유지.
- DS3231의 12시간/24시간 형식 해석. 부팅 시 RTC 시간을 임의로 다시 쓰지 않음.
- STOP=0, RUN=1이라는 실제 enum 기준으로 LED 연결 수정.
- LCD는 각 줄 16칸을 채우고 바뀐 문자만 전송. 날짜와 스톱워치 화면 전환 모두 동일 방식.
- LCD 초기화 및 clear 대기시간 반영. E가 LOW일 때 데이터를 먼저 설정하고 HIGH→LOW 펄스 출력.
- main/ISR이 공유하는 카운터·목표에 volatile 및 짧은 임계구역 사용.
- 모터를 움직이지 않는 순간 release하지 않고 여자 패턴 유지.

## 8. 빌드 및 확인 범위
STM32CubeIDE에서 이 통합 프로젝트를 선택 → Refresh(F5) → Project Clean → Build Project → 해당 프로젝트 Debug/Run.
새 파일 Core/Src/ap/ClockNeedle.c가 소스 목록에 포함되는지 확인.
.ioc에는 모터용 PA0/PA1/PA4/PB0 출력 핀을 추가했다. 나머지 모터 핀은 원래 출력 설정이다.
ClockNeedle_init도 GPIO를 초기화하므로 현재 소스로 바로 빌드할 수 있다.

검증:
- ARM GCC로 35개 소스를 새로 컴파일하고 링크 성공.
- 응용 코드는 -Wall -Wextra -Werror 통과. ST HAL은 CubeIDE 기본 -Wall 적용.
- 실제 C의 목표식과 ISR 제어 흐름을 추출한 시뮬레이션으로 24시간 전체 목표 범위, 12시 경계, 59초→0초, 모드 변경, CLEAR, STOP 유지, 핀 중복 검증.
- 실제 보드 다운로드/모터 회전/부하/전원/I2C 연결은 아직 검증하지 않음.
- 모터가 반대로 돌거나 한 바퀴 각도가 다르면 forward 또는 N을 실제 하드웨어에 맞춰 조정.
